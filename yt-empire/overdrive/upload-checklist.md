# First-Upload Checklist (step by step)

## A. Channel creation (~10 min)
1. youtube.com → sign in → Create channel → name: **HonestReps** (grab handle @HonestReps; fallbacks in brand-kit.md)
2. YouTube Studio → Customization → Branding: upload `channel-identity/pfp.png`, `banner.png`, `watermark.png` (watermark display: **Entire video**)
3. Basic info: paste bio + tagline from `channel-identity/brand-kit.md`; add links placeholder for {{AFFILIATE_LINK}}
4. Settings → Upload defaults: paste FTC disclosure line into default description footer

## B. Affiliate (before first upload if possible)
5. Apply at https://www.speediance.com/pages/affiliate (steps in `monetization/affiliate-dossier.md`)
6. On approval, run the one-liner in `monetization/replace-link.md` → verify `grep -rn '{{AFFILIATE_LINK}}' .` returns nothing

## C. Human QC (non-negotiable)
7. **Watch `video-01/final.mp4` end to end** — checklist in `video-01/QC-NOTES.md`
8. Check thumbnail 01 at phone size (`thumbnails/_legibility-168px.png`)

## D. Upload video #1
9. Upload `final.mp4`; paste title/description/tags/pinned comment from `posting-packages/01-creatine-truth.md`
10. Thumbnail: `thumbnails/01-creatine-truth.png` (or run YouTube's A/B "Test & compare" with 01A + 01B)
11. **Altered content disclosure: answer YES** to the synthetic/AI-generated content question (this video is AI-generated — required)
12. Not made for kids; add to a new "Honest Fitness Explainers" playlist
13. End screen (last 10s over the outro card): Subscribe element + "next video" element; add 1 info card at 3:14 pointing to description link
14. Publish Tue 15:00 UTC per `overdrive/30-day-calendar.md`; pin the pinned comment immediately
15. Next day: upload `short-teaser.mp4` as a Short, comment-link to the full video

## E. After publish
16. Reply to every comment for 48h (pinned comment promises it)
17. Day 14: check A/B thumbnail result; adopt winner (see growth-playbook.md)
